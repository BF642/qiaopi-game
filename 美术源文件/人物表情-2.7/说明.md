# 2.7 人物眼睑与闭口嘴角

运行资源为 `Assets/Resources/CharacterFaceMotion.json`，由现有角色的同源皮肤 UV 对应生成。眼球、原始 FBX、衣服、发型以及各角色脸型没有被替换。

- `points`：左右眼睑闭合位移。来源为项目已有的 MakeHuman `eye-left-closure.target` 与 `eye-right-closure.target`（文件头声明 CC0）。幅度为原生目标的 1.05 倍，用于原工程已扩大的眼睑开口。
- `mouth`：轻微闭口嘴角放松。来源为同目录 `mouth-corner-puller.target`，仅使用其 6% 或 8.5%；保留原始闭口基础。
- 每条记录含皮肤 UV `u/v` 和角色局部坐标位移 `x/y/z`，单位为原角色的米制空间。不同人物使用各自变形后头部的映射结果。
- 运行时只修改 `CharacterPerformance` 所有的临时网格副本，并生成两个独立 blendshape。对源模型、共享材质及玩家存档无写入。
- `CharacterFaceMotion.Weight` 控制非同步、约 0.2 秒的眨眼；常态仅施加 2%–3.5% 的轻微眼睑放松。重置姿态时两个形变都归零。
- `WorldFaceMotionQA` 可输出每人原脸、放松、闭眼三张 Unity 原材质肖像；编辑器姿态检查验证眼球顶点不变、形变幅度与恢复。

生成时采用项目已有的 MakeHuman 形态源数据，并在与原角色相同的细分皮肤拓扑上计算 UV 对应位移。修改 JSON 或运行时幅度后，应重新对全部角色执行 Unity 人物检查并人工检查闭眼图，避免只有主角正常、其他脸穿出眼球。
