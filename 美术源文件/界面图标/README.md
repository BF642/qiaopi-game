# 侨批界面图标

七枚原创矢量图标，使用纸白、朱砂、墨绿与旧金色。透明底，兼顾纸面与深色HUD。

- letter：附有朱印的信封
- album：带闽南古厝页签的线装图册
- map：折页地图、路线与罗盘
- help：引路灯笼
- brand：出海帆船徽记
- write：信纸与毛笔
- livelihood：货箱与钱币

SVG为可编辑源文件，不依赖字体或外部图片。游戏读取 Assets/Resources/UI/Icons 中的256×256透明PNG。

如需重新导出，在自己的Node环境安装sharp后运行 `node render-icons.cjs`。SVG设计与PNG均遵循本仓库原创内容协作使用说明。
