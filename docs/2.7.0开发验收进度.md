## 室内修正及运行范围

六处写批房覆盖泉州、泉州海口、海外码头、商铺街、侨居和侨批局。测试以正常速度沿路径走到书桌，落座后检查真实座位视角、至少三面墙和窗、座位及入座点上方实际可见网格屋顶；起身后仍在原位置。该测试采用三国交错样本，不等于每处房间的全部国家组合均已运行。

八处核单点为商号三处、批局三处、首日码头理账两处。旧版路边核单桌已移除，材料回到室内桌案、货架或账棚；陈记补全了房顶和山墙。测试实际走到每处站位，朝向原件后交互，确认头顶可见屋顶，错答不加奖励，正确答案只结算一次，磁盘存读档保留已核记录与任务进度。

另检查草稿保留、搬货时不进入写信状态、航行中不在路边打开编辑器、取消寻桌，以及商号、批局和码头三个合成的受阻旧落点能在附近恢复。可站立的存档坐标保持不动。测试使用独立临时文件，全程静音，完成后核对原旅程、首章试玩、调查试玩及其备份和临时文件、声音偏好均未改变。194 项是自动化断言数，不是玩家数或人工试玩次数。

首轮画面复查发现室内工作台的大黑招牌过大，最终构建已换为约 40 厘米宽的桌边木签，保留墙上店招。实看确认桌案视线不再被大牌遮挡。下图原样取自最终运行截图；信件为虚构测试文字，不含玩家私人资料。

## 人物复查范围

本轮在现有十二套人物上调整皮肤、眼睛和头发材质，加入眼睑闭合、嘴角轻微放松与待机动作。肖像测试使用真实对话镜头、灯光及人物实例，分帧渲染，避免连续截图实际上仍是同一帧张眼画面。全部 36 张图产生成功，其中四人的闭眼及放松状态另作人工目视检查。

这些结果证明表情和渲染按预期变化，不代表已经重做精细角色：脸部和头发仍低细节，服装没有重做，也未重新雕刻人脸或导入高精度新模型。

## 调查实走

最终 `inquiry-verified.log` 记录 `INQUIRY_RUNTIME_ALL_PASSED assertions=189 checkpoints=12`。测试正常速度走完三条路线，读取九处原件，与三位旧识实际交互求助，验证远处不能直接提交、错项不会推进剧情、核认后仍需完成原剧情选择，并完成 12 个独立磁盘保存回读检查点。全过程保持第一人称和静音，不改原有玩家文件与声音偏好。

实走样本分别是新加坡信局、槟榔屿码头、仰光家信；三国九条组合的业务规则由编辑器检查覆盖，未将其写成九条全部实走。场景重建及读档当帧规划的路径回归也通过，避免新旧物理状态未同步导致目标明明可达却找不到完整路径。189 是本次运行断言数，12 是保存回读检查点数，不是人工试玩人数。

## 复测入口

从 Unity 菜单「侨批 → 导出 Mac 游戏」构建，会先执行项目回归、新增调查和街区检查。运行生成的应用时使用以下测试入口；输出目录由对应参数指定：

| 测试 | 启动参数 | 成功标志 |
| --- | --- | --- |
| 室内短测 | `-qiaopi-writing-review -qiaopi-writing-output <截图目录>` | `WRITING_REVIEW_ALL_PASSED` |
| 调查路线 | `-qiaopi-inquiry-test -qiaopi-inquiry-output <截图目录>` | `INQUIRY_RUNTIME_ALL_PASSED` |
| 人物表情 | `-qiaopi-face-motion-review -qiaopi-face-motion-output <截图目录>` | `FACE_MOTION_QA_ALL_PASSED` |

本机另备「更新并检查侨批.command」，用于构建保留配音的本地工程并静音验证调查路线；以本次实际日志为准，不把脚本存在视为执行完成。独立调查试玩使用 `qiaopi-inquiry-preview-v1.json`，不覆盖原旅程和首章试玩。本轮未上传侨批正文、更新 GitHub Release 或安装 iPhone。
