# 2.5.0 首章试玩：范围与验收

2026-10-08。首章串联泉州家庭日常、离乡、海外首份工作、亲手写批和数周后的第一封回音。第一次回批后可以继续自主谋生。20～30 分钟是设计目标，尚未经过真人完整计时。

## 正式入口与存档

帮助菜单的「首章试玩 · 独立存档」会先保存当前旅程，再载入独立试玩进度；没有试玩存档时才新建。从同一菜单的「返回原旅程」回去。读取失败时留在当前旅程，不覆盖损坏存档。

- 原旅程：`qiaopi-world-v1.json`。
- 首章试玩：`qiaopi-chapter-preview-v1.json`。
- 新游戏启用家庭活动；旧存档保留原有推进方式，不强制重做开场。
- 声音沿用玩家设置。本次更新前后音效、音乐与语音均为关闭。

## 新增内容的实际边界

家庭活动包括跟妻子到门外采买、提篮回灶边、帮母亲收一趟谷子、教阿满写「家」或「归」、一起端饭。妻子实际走到摊位才开始采买对话；母亲和阿满沿院内短路走向饭桌。采买用家中预留的家用，不重复扣玩家盘缠；重复互动不重复奖励。自由写批在家庭活动完成后开放，避免一边提篮一边切换到书桌而卡住目标。

回批可以提起已经发生的家庭日常。选择「如实说出难处」时，才回应被记录的海外工作、欠薪和身体状况；报平安、谈读书不泄露这些细节。自由正文原样保存，不做语义识别。回批在寄出时定稿，随叙事时间延迟送达。首日经历优先回应，避免再重复一段泛泛的第一天工作说明。

自主谋生的欠薪事件新增「暂且忍下」，须到结账处核认已经收到的工资；没有额外发薪，未追回的四枚仍是欠款，身体减二、信用不变，同乡会记住处理方式。此事件发生在首封回批之后，不能当作首章新增的强制劳动。

人物增加前臂弯曲与轻微手部变化。实际截图确认记账笔尖贴纸、袖腕连续，NPC 弯肘签字并交回单张回执。手指夹持仍偏松，NPC 手型偏张开，工友抱货有几像素接触间隙；本轮没有完成精细逐指抓握，也没有重做人脸。

## 可复跑入口

在单个独立游戏进程运行，不与另一份游戏同时打开。使用可写的截图和日志目录。

```sh
"Builds/侨批·纸短情长.app/Contents/MacOS/侨批 · 纸短情长" \
  -qiaopi-chapter-test -qiaopi-chapter-output "$PWD/ChapterQA" \
  -screen-width 1440 -screen-height 900 -screen-fullscreen 0 \
  -logFile "$PWD/ChapterQA.log"
```

- 完整成功标记：`CHAPTER_RUNTIME_ALL_PASSED`。只检查家庭段可加 `-qiaopi-chapter-home-review`，相应标记为 `CHAPTER_HOME_REVIEW_PASSED`。
- 桌面触屏布局：加 `-qiaopi-touch-preview`，推荐 1600 × 737。
- 欠薪忍让复核：`-qiaopi-nanyang-test -qiaopi-nanyang-endure-review`，成功标记 `NANYANG_ENDURE_REVIEW_PASSED`。
- 人物与工作动作：沿用 `-qiaopi-performance-test -qiaopi-performance-review`，成功标记 `PERFORMANCE_REVIEW_ALL_PASSED`。
- 正常独立试玩：`-qiaopi-chapter-preview`，或在游戏帮助菜单进入。此模式是可保存的正式试玩，不是自动检查。

主要新增文件为 `HomeChapter.cs`、`WorldHomeChapter.cs`、`WorldChapterPreview.cs` 和 `WorldChapterQA.cs`。家书、欠薪与人物动作扩展既有相应模块；17 次原主线选择和 8 类结局继续沿用。
