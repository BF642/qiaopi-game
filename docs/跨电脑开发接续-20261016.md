# 跨电脑开发接续 · 2026-10-16

## 打开当前工程

Unity 6000.6.0f1；仓库根目录就是工程目录。先安装 Git LFS，克隆并执行 `git lfs pull`。已克隆的电脑先保存本地改动，再 `git pull --ff-only` 和 `git lfs pull`；如果提示分支分叉，先处理本地提交，不要强制覆盖。

执行 `python3 tools/verify_checkout.py` 检查 LFS 资源是否完整。Windows 也可用 `py -3 tools/verify_checkout.py`。不要把只有几行 version/oid/size 的 LFS 指针当成真实模型。

Unity 首次导入大型模型需要时间；Library、Temp、Logs 不上传，编辑器会自动重建。无需复制另一台电脑的 Library 缓存。场景为 Assets/Scenes/Qiaopi.unity，主体内容由 WorldGame 与 WorldFactory 在运行时生成。
