# 2.8.0 路人独立外貌验收

记录日期：2026-10-11。本轮已在 Unity 中检查外貌，并使用公开素材版 Mac 应用完成七个场景的路人实走验收。本文只记录路人部分；文生、母亲和妻子的美术调整另行记录。

## 外貌与身份

37 位路人各有固定身份和独立脸型，分别调整脸宽、下颌、颧颊、眼距、鼻形、嘴宽与下巴。外貌按身份指定，不随出生顺序、站位、转向或重新进入场景随机变化。衣服颜色也与身份绑定。

这些脸型使用 **7 类既有发型、衣身和基础头部拓扑**，不是 37 套全新高精度角色。每位路人持有自己的头部网格，剧情角色的原模型、身体骨骼、权重和贴图坐标保持不变。与剧情人物共用基础衣身的独立居民不再因此被隐藏。

Unity 原生对照渲染覆盖全部 37 人。复查中发现的眉间黑色碎线已修复；眼球保持原来的圆度，眼窝与眉毛同步贴合。现有发型、服装和部分旧胡须细节仍需后续美术改进。
