## 必要的重新导入方式

1. 使用 Blender 后台执行 `tools/import_existing_cast.py`，在 `--` 后依次传入工程目录、角色名和现有 GLB 路径。这只做保留几何的格式与绑定转换。
2. 用 Python/Pillow 执行 `tools/pack_native_metallic.py`，参数为该角色的 MeshyMotion 资源目录。
3. 在 Unity 中调用 `Qiaopi.Editor.ExistingCastImport.Install("角色名")` 连接原生贴图、材料与现成动作。通常正常克隆后不需要重跑导入工具。
