# 侨批 · 纸短情长

从泉州出发，亲自走一段华侨人生。Unity 中文第一人称 3D 剧情游戏。

## 当前开发版 · 2026-10-16

本分支包含当前电脑版工程：启动登录封面、泉州家庭日常、海外自主谋生、自写侨批、图集共建，以及已接入的人物和区域建筑。启动后点击“登录”或按回车进入；继续读取本机原有旅程。

- 从泉州家庭日常走向离乡出海；新加坡、槟城、仰光和三宝垄的落脚地与谋生内容。
- 搬运、核账、递批、工作与休息；盘缠、身体、亲情和信用影响后续经历，当前有 8 类结局。
- 在室内书桌前写侨批、附银、存稿；正文原样保留，回信根据明确选择的心意与已记录的经历回应。
- 玩家整理侨批图片、家族故事、来源与授权，生成本地投稿包。**尚未接通在线上传、收件确认与后台审核服务。**
- 泉州整屋、三宝垄仓库等已接入；各地建筑及剩余人物仍在继续替换。不要将本开发版描述为全部资产已完成。

## 在另一台电脑继续开发

需要 **Unity 6000.6.0f1**、Git 和 **Git LFS**。请先装好 Git LFS，再克隆：

```sh
git lfs install
git clone https://github.com/BF642/qiaopi-game.git
cd qiaopi-game
git lfs pull
python3 tools/verify_checkout.py
```

**不要只下载 GitHub 的普通源码 ZIP**：模型、动画、贴图和 Blender 文件使用 Git LFS，普通 ZIP 可能只有资源指针。不要减面或降低贴图精度来替代下载原文件。

在 Unity Hub 中添加本仓库根目录，等待首次资源导入完成，打开 `Assets/Scenes/Qiaopi.unity`，点击 Play。首次进入显示登录界面。Mac 可使用菜单 **侨批 → 导出当前电脑版（保留原始资源）**，输出到 `Builds/`。其他桌面平台需安装对应的 Unity 构建支持；当前只验证了 Mac 成品。手机版已停止开发，历史文件保留。

详细操作、修改入口、当前待办和构建边界见 [跨电脑开发接续说明](docs/跨电脑开发接续-20261016.md)。原有 Releases 仍为旧版 2.0.4；本次更新的是可编辑源码，未将旧安装包冒充新版本。

## 操作与保存

- WASD 行走，Shift 快走，按住鼠标右键转头，E 互动。
- Enter / 空格推进对话，数字键选择回答；J 侨批匣，M 地图，G 图集，Esc 帮助或收起面板。
- 帮助里的“首章试玩”使用独立存档；可返回原旅程。
- 存档、图集投稿草稿与音量偏好保存在每台电脑本地，Git 不同步玩家私人资料。

修改后提交 Pull Request，或由维护者授予推送权限。当前要求见 [AGENTS.md](AGENTS.md)：只做电脑版，保留原始模型精度，人物与地区建筑按身份、地点和用途区分。

工程保留字体和第三方素材的许可文件；详见 [素材与第三方说明](THIRD_PARTY_NOTICES.md) 和 [协作使用说明](协作使用说明.md)。公开工程不附带原本机 macOS 系统语音录音；没有录音时字幕、剧情和播放接口仍可运行。旧版本记录保留供追溯，以本页与接续说明为当前入口。
