# 《纸短情长》原创器乐主题

本配乐为《泉州侨批》游戏创作，以同一段原创旋律写成“泉州思乡”“海路南洋”“回批归途”三种编配。它采用程序合成的呼吸管乐、拨弦、弓弦与木质拍板音色意象，**不是传统南音曲牌，不是真人演奏或南音实录**。没有使用商业歌曲、下载曲目、现成旋律循环或外部采样。

南音与闽南、海外闽南社群的乡音联系，以及其缓慢、简雅的音乐气质，是本次创作的文化参考。器乐意象参考洞箫、横抱琵琶、三弦、二弦与拍板的分工；音色由数学合成产生，并不宣称精确复刻这些传统乐器的声学或演奏法。[UNESCO 南音介绍](https://ich.unesco.org/en/RL/nanyin-00199)、[福建省政府南音介绍](https://www.fujian.gov.cn/english/cultureandtravel/cultureandarts/202503/t20250324_6787125.htm)。

## 三种编配

| 文件 | 场景 | 时长 | 速度 | 配器性格 |
|---|---|---:|---:|---|
| `HomeLetter.wav` | 泉州、家书与故乡 | 80.000 秒 | ♩=48 | 管乐陈述主题，左右拨弦轻声回应，弓弦保留较多留白 |
| `SeaLetter.wav` | 海路、船舱与南洋 | 76.800 秒 | ♩=50 | 主题不变，增加轻巧拨弦回答，空间稍开阔，仍保持缓慢呼吸 |
| `ReturnLetter.wav` | 回批、侨批匣与归途 | 83.478 秒 | ♩=46 | 更多柔和弓弦支撑，少量短轮指，速度更从容，尾句回到主音 |

Unity 音频位于 `Assets/Resources/Music/`。三个文件均为 **44,100 Hz / 16-bit PCM / 双声道 WAV**，按完整 16 小节设计循环。各声部尾音和混响以周期方式折回开头，不需要在游戏里剪去尾巴或添加静音。

可直接分享的单曲试听文件位于工程同级：`泉州侨批-主题配乐.wav`。它采用“泉州思乡”编配，末尾有 1.5 秒淡出，适合独立试听；游戏中应使用上述循环版。

## 原创主题与结构

全曲采用现代 MIDI 音高记录，以 D、F、G、A、C 五个音为主要材料，4/4 拍，16 小节。不是传统工尺谱，也不借用已有南音旋律。八个乐句各占两小节，通过较长尾音、气口和拨弦回答形成“问候—远行—回信”的连续感。

| 乐句 | 主旋律音名（音区按 MIDI 标准，中央 C 为 C4） |
|---|---|
| 1 | D4 — F4 G4 — A4 —— G4 F4 |
| 2 | G4 F4 — D4 —— C4 D4 —— |
| 3 | F4 G4 A4 —— C5 — A4 —— |
| 4 | G4 —— F4 — D4 ———，留白由拨弦回答 |
| 5 | D4 — F4 G4 — A4 —— C5 A4 |
| 6 | D5 —— C5 A4 —— G4 F4 —— |
| 7 | G4 — A4 — C5 —— A4 G4 —— |
| 8 | F4 —— G4 F4 — D4 ———，回到首句的主音 |

上表只用于快速阅读；准确起音、时值、力度和声部请以 `*-score.json` 与 MIDI 为准。三种编配均含 39 个管乐主旋律音。拨弦分别为 48、64、53 个事件；拍板分别只有 4、6、5 个轻触事件，不构成密集节拍。

## 音色与混音

- 管乐：多谐波气柱意象、延迟进入的轻颤音、缓慢气息包络与微量带限气流噪声。
- 拨弦：不同衰减速度的弦振动模态、拨弦位置对泛音的影响、细微复弦差频及轻木质瞬态。
- 弓弦：柔和起弓、轻颤音与克制的摩擦音，作为持续支撑。
- 拍板：短促的木质共振模态，保留稀疏落点。
- 空间：短早期反射与轻漫反射尾音；左右声部有位置差异，主旋律保持接近中央。

三首均保持约 −22 LUFS 的整体响度；−3 dBTP 是峰值上限。实际真峰低于该上限，保留对话与环境声的混音空间。没有钢琴主旋律、方波主音色或西式鼓组。

## 可编辑与重现

- `HomeLetter.mid`、`SeaLetter.mid`、`ReturnLetter.mid`：多轨 MIDI，可导入本机 GarageBand、Ableton Live 或其他支持 MIDI 的音乐软件。
- `*-score.json`：精确音符事件、速度、种子与表达力度。
- `generate_score.py`：完整谱面、合成器和混音工程，以固定随机种子重现三首 WAV。

MIDI 的 General MIDI 乐器号只作为通用试听提示，不能携带本工程的自定义音色。导入其他软件后若想保留最终听感，应播放配套 WAV；重新配器则可编辑 MIDI。

重现所需：Python 3、NumPy、FFmpeg。运行：

```sh
python3 generate_score.py
```

默认将 WAV 写入工程 `Assets/Resources/Music/`，中间文件写入 `音乐源文件/render-work/`。也可使用 `--output-dir` 和 `--work-dir` 指定位置。未使用系统扬声器或修改电脑音量。
